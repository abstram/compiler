# Alakazam (AZM) Compiler 
Alakazam is higher level assembly-like language that's designed to feel just like writing actual Assembly without most of the annoying parts, while taking away almost no actual control (e.g. register management). It targets 32-bit x86 Netwide Assembly, and the output is meant to be linked to [SMGK (Simple Multi-processing Graphics Kernel)](https://github.com/eshaan312/smgk).
